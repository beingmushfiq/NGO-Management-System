# 11 — Deployment & Build Verification

## 1. Local Development
```bash
cd ngo-frontend
npm run dev
# Server running at http://localhost:5173
```

## 2. Production Build & Static Hosting
```bash
npm run build
# Generates optimized static assets in /dist
```

## 3. Hosting Targets
- Compatible with Vercel, Netlify, Cloudflare Pages, AWS S3 / CloudFront, and Docker Nginx containers.
