# 01 — Requirements Analysis

## 1. Primary Objectives
The platform must serve three distinct user archetypes with tailored workflows:
1. **Admin Portal**: Executive portfolio management, branch auditing, loan approvals, staff allocation, and financial compliance reporting.
2. **Staff Portal**: Field-officer-focused daily route execution, customer search, and rapid dual-account collection entry.
3. **Customer Portal**: Transparent self-service borrower dashboard displaying outstanding loan balance, repayment progress, savings ledger, and receipts.

## 2. Core Business Workflows
- **Dual-Account Combined Collection**: A signature feature where a single payment entry atomically debits the borrower's loan installment (reducing outstanding debt) and credits the borrower's savings account (increasing balance).
- **Loan Origination Wizard**: 3-step structured application capturing borrower, principal, service charge %, duration, and calculating installment schedules automatically.
- **Member Savings Vault**: Regular deposit accumulation, interest management, and member withdrawal verification.
- **Institutional Reporting**: Daily collection sheets, portfolio quality (PAR), branch performance matrices, and exportable statements.
- **Bilingual Experience**: English & Bengali (বাংলা) typography and financial conventions.
